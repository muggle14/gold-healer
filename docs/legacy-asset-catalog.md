# Legacy asset catalogue

## Service artwork

`assets_gold_v2/` contains paired `gold2` and `gold3` artwork for Akashic Records,
Astrology, Automatic Writing, Candle Magic, general healing, Inner Child Healing,
Numerology, Quantum Healing, Reiki, Tarot, Vaastu, and Violet Flame, plus the historical
`allofferings.png` composite. These assets are not loaded by the current website.

## Banners

`banners_gold/` contains historical call-to-action, moon, and sun compositions in mobile
and desktop sizes. `sun_banner_peacock.png` was the previous social image. None of these
files is loaded by the current homepage.

## Brand history

`branding/brand.jpeg`, `branding/brand_v2.png`, `branding/brand_v3.png`, and
`branding/garima_hero.jpg` are earlier poster or logo generations. The approved website
system now uses the source-faithful transparent derivatives documented in
`branding/README.md`.

## Retention decision

All legacy assets remain in place because they have design-history value. No destructive
cleanup was performed. A future archive move requires explicit approval and must use
`git mv`.
